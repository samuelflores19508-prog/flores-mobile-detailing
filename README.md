# Flores Mobile Detailing Demo Website

This is a mobile-friendly one-page demo website for a fictional local mobile car detailing business.

## Project goal

The goal of this project is to show how a simple local business website can help visitors quickly understand:

* What the business offers
* Why the service is convenient
* What services are available
* Where the business serves customers
* How to request a quote

## What the site includes

* Responsive HTML and CSS
* Clear hero section
* Quote-focused call-to-action
* Tap-to-call link structure
* Service package cards
* Trust strip
* Service-area section
* FAQ section
* Contact form layout
* Demo disclosure
* Keyboard skip link
* Basic SEO metadata

## Testing completed

I tested the page at a narrow mobile width of 375px and confirmed there was no sideways scrolling. I also used PageSpeed Insights to identify publishing and accessibility/SEO issues, then made improvements to the HTML structure, metadata, keyboard navigation, and project documentation.

## Status

This is a portfolio demo project. The business details are fictional.
