# Flores Mobile Detailing — Portfolio Case Study

## Project type

One-page local business landing page.

## Project goal

The goal of this project was to create a simple, mobile-friendly website for a sample mobile car detailing business. The page is designed to help a visitor quickly understand what the business offers, why it is convenient, and how to request a quote.

## Business problem

Many small local businesses rely on word of mouth, social media, or an incomplete online presence. That can make it harder for potential customers to understand services, pricing, service area, hours, and contact options.

## What I built

I built a responsive one-page website with:

* A clear hero section explaining the service
* A quote-focused call-to-action
* A tap-to-call link
* Service cards for the main packages
* A trust strip
* A service-area explanation
* A review/testimonial section
* FAQ content
* A contact form layout
* Sample phone, hours, and service-area details
* Mobile-responsive CSS

## Why these sections matter

The page is structured to answer the questions a local customer usually has:

1. What does this business do?
2. Where does it serve customers?
3. Why should I trust it?
4. How do I contact it?

## Tools used

* HTML
* CSS
* Chrome DevTools
* Mobile responsive testing at 375px width

## Current status

The page works locally, responds correctly on narrow screens, and has no sideways scrolling at 375px. The next step is publishing the page online and testing it with public page-quality tools.

## What I would improve next

For a real client, I would add real business photos, real reviews, a working form, a real phone number, actual service-area copy, and a Google Business Profile link.

## Testing and improvements

After publishing the site, I ran a public page-quality test and recorded the mobile and desktop results. The first published version scored 100 for performance on both mobile and desktop. I then made improvements for accessibility, SEO metadata, keyboard navigation, semantic navigation, and demo transparency.

These changes matter because a business website should not only look good. It should also be usable, understandable, mobile-friendly, and easy to share with potential customers.

I also fixed a color contrast issue in the contact section after PageSpeed identified the “Request a quote” eyebrow text as too low-contrast on the dark background.
